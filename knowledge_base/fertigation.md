# 水肥一体化配比方案

## 适用作物与灌溉方式
- 适用：棉花、番茄、玉米、小麦、果树
- 灌溉方式：滴灌（适合大多数作物）、微喷灌（叶菜类）

## 基础肥料选择
### 大量元素水溶肥
- 尿素（含N 46%）：溶解性好，作追肥首选
- 磷酸一铵（MAP，12-61-0）：酸性，适合碱性土壤
- 磷酸二氢钾（0-52-34）：花果期追施
- 硫酸钾（K2O 50%）：氯敏感作物首选
- 硝酸钾（13-0-46）：温室和果树

### 微量元素
- 硼砂/硼酸：棉花、番茄蕾期-花期
- 硫酸锌：玉米制种（提高结实率）
- 硫酸亚铁/螯合铁：果树缺铁黄化
- 钼酸铵：豆科作物固氮

## 作物配比方案

### 棉花（蕾期-花铃期）
- N:P2O5:K2O = 1:0.3:0.5
- 每次滴水追施：尿素3-5kg/亩 + 磷酸一铵1-2kg/亩 + 硫酸钾1.5-2kg/亩
- 全生育期N：18-22kg/亩

### 加工番茄（果实膨大期）
- N:P2O5:K2O = 1:0.4:1.2
- 每次滴水追施：尿素3-4kg/亩 + 磷酸二氢钾2-3kg/亩
- 全生育期K2O：10-12kg/亩（番茄喜钾）

### 冬小麦（返青-拔节期）
- N:P2O5:K2O = 1:0.5:0.3
- 返青追施：尿素10-15kg/亩
- 拔节追施：尿素10-15kg/亩 + 磷酸一铵5kg/亩

### 玉米制种
- N:P2O5:K2O = 1:0.6:0.4
- 拔节期追尿素15kg/亩
- 灌浆期叶面喷施磷酸二氢钾0.3% + 尿素1%

## 施肥操作要点
- 清水润管：先滴水20-30分钟，湿润土壤
- 注肥：注入时间为总灌水时间的50%-70%
- 冲洗：施肥结束后继续滴清水15-20分钟（冲洗管道防堵塞）
- 浓度控制：肥料母液稀释100倍以上
- pH值：保持5.5-6.5（酸性环境防沉淀）

## 注意事项
- 含钙肥料（硝酸钙）与含磷/硫酸根肥料分开施用（防沉淀）
- 碱性水（pH>7.5）先调酸再施肥
- 高温时段（12:00-16:00）不施肥
- 滴灌带末端取样测EC值（≤2.5ms/cm）
